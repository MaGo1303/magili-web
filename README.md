## 📌 Descripción

Magili es un proyecto web con una arquitectura cliente-servidor clásica: la interfaz está construida con **HTML, CSS y JavaScript**, y el servidor está desarrollado en **Node.js**.

## 🚀 Cómo ejecutar

Requisitos: [Node.js](https://nodejs.org) con npm instalados.

```bash
# 1) Instalar dependencias
npm install

# 2) Arrancar en modo desarrollo
npm run dev

# 3) Compilar y arrancar en modo producción
npm run build
npm start
```

En modo desarrollo la aplicación queda disponible en `http://localhost:3000`.
